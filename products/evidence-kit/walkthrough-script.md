# Ninety-second launch-evidence walkthrough

## 00:00–00:12 — Scope

Name the product, public journey, browser, viewports, and observed UTC window. State that this is normal-user observation only.

## 00:12–00:28 — Decision

Say GO, CONDITIONAL GO, or NO-GO. Give the single reason that determines the call.

## 00:28–01:02 — Highest-impact evidence

Show no more than three findings, in P0 → P1 → P2 order. For each:

1. show the public URL and journey step;
2. state the expected result;
3. show the observed result;
4. name the screenshot or clip that proves it;
5. state the narrow next action.

## 01:02–01:18 — What passed

Name the critical parts that worked. This keeps the report proportionate and prevents a defect list from sounding like a product verdict.

## 01:18–01:30 — Owner and retest

Name the first fix, owner, due time, and exact journey to rerun. End with what evidence would change the launch call.
