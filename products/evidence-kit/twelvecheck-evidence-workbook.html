LAUNCH EVIDENCE, NOT OPINIONS.

A reusable, offline workbook for twelve normal-user SaaS launch checks. Capture the public URL, UTC time, viewport, expected result, observed result, impact, and evidence reference—then export a client-ready report.

Your data stays here.

This file has no analytics, account, upload, or network request. Work is saved only in this browser using localStorage. Export JSON for backup before clearing browser data.

01 / Project

Use public URLs and safe test data only. Never paste credentials, customer data, secrets, private URLs, or regulated information into this workbook.

Impact rule: P0 blocks the launch journey. P1 creates material conversion, trust, or progress friction. P2 is clarity or polish. If the evidence does not support the impact, lower the severity.

03 / Twelve checks

Write what a normal visitor expected and what actually happened. Use one evidence reference per finding: a screenshot filename, short video timestamp, or saved browser capture.
